Atlas Splitter

スプライトシートとアトラスを分割

English · 中文 · 日本語 · 한국어

Atlas Splitter は、インディーゲーム開発者と 2D / ピクセルアーティスト向けの macOS アトラス分割ツールです。スプライトシート、UI 合成、タイルアトラスをドラッグして、すぐに使える個別画像へ分割できます。アカウント不要・クラウドアップロードなし。素材は常にあなたの Mac に残ります。

Mac App Store の掲載は審査中です。公開後にストアリンクを追加します。現在は公式サイトから購入できます。

クイックスタート

  1. アトラスを開く（ドラッグ＆ドロップ、または ファイル → 開く）。
  2. グリッドまたはフリーモードを選ぶ。
  3. PNG / JPG / BMP を一括書き出しし、ゲームプロジェクトへ投入。

3 つの明確な経路

1）グリッド（規則的な配置）

スプライトが揃っている場合、セル幅/高さ、行/列、マージン、間隔を設定して一気に分割します。

2）フリー（不規則な配置）

揃っていない場合は次が使えます：

  • 魔法の杖での背景除去 + 手動矩形での微調整
  • 透明または単色背景をクリック（自動）して多数の個別スプライトを枠付け
  • セル一覧で一括リネームと整理

3）書き出しと端の処理

  • 不透明範囲に合わせる、または透明パディングを保持 / 追加
  • ファイル名テンプレートで PNG / JPG / BMP を一括書き出し
  • すべてローカル処理 — アップロードなし、ユーザーデータ収集なし

想定ユーザー

Atlas Splitter は「SNS 用のグリッド分割」向けではありません。ゲーム制作で繰り返される切り分け——大きなシート内の何百もの小物、キャラフレーム、UI スライス——手作業では遅く、純粋なグリッドではしばしば合いません。

透明で形状がはっきりしたアトラスなら、自動フレーム + 書き出しはおおよそ数分程度。背景が複雑なときはフリー + 魔法の杖が確実な代替になります（元に戻し可能）。
