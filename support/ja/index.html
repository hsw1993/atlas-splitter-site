インディーゲーム向け Mac 切り分けツール。1 枚のアトラスから自動フレーム、グリッド / フリー描画、魔法の杖での清掃、そしてローカル書き出し。アカウント不要・クラウドなし。素材は Mac に残ります。

スプライトがはっきり分かれているときに最も効果的。粘着や複雑な背景はフリーまたは杖で補ってください。公式サイトで買い切り（$7.99）。Mac App Store 審査後にストアリンクを追加します。

製品の入手方法

  1. 購入：公式サイトまたは Creem チェックアウト（買い切り $7.99）。
  2. ダウンロード：Creem から公証済み .dmg をダウンロード（決済完了ページ、領収メールのリンク、またはカスタマーポータル）。
  3. インストールと有効化：Applications にドラッグして起動し、メールの AS1.… キーを貼り付けて Activate。

詳細手順：atlassplitter.com/get/

クイックスタート

  1. アトラスを開く（ドラッグ＆ドロップ、または ファイル → 開く）。アプリ内に Samples あり。
  2. サイドバーでグリッド / フリーを切替。
  3. タイル（またはアトラス + JSON）を選んだフォルダへ書き出し、ゲームプロジェクトへ投入。

できること（公式サイトの紹介と一致）

自動フレーム

フリーモードで背景を 1 回クリックすると、多数のスプライトを一括枠取り — 透明または単色塗りで分かれているシート向け。PNG は透明、JPG/BMP は単色キーをクリック。設定 → 自動フレーム → 最小サイズ…（または自動ツールをダブルクリック）で小さい島を無視（デフォルト約 ≤ 8×8）。

グリッドとフリーハンド

グリッド：規則的なタイルセット — セルサイズ、行/列、マージン、間隔。セルサイズはアニメ揃え用の論理キャンバス。端の処理：切り抜き（端の余りを破棄、完全なセルのみ）またはパディング（セルサイズ維持、余分な行列は透明）。セルにホバーでプレビュー。

フリー：不規則な配置は矩形を手描き（オレンジ枠 = 論理キャンバス）。ハンドルでリサイズ。セル一覧で整理・リネーム。右クリックで不透明範囲に合わせる / リストに追加 / 画像をコピー / 削除。重なり：右クリック → 選択 → #id。

魔法の杖

自動フレームのあとが汚れているときに、背景を選んで透明化。不透明をクリック、Shift+クリックで追加。右クリック：1px 拡張 / 1px 縮小 / 透明化 / 反転 / 選択解除。杖をダブルクリック（または 設定 → 魔法の杖 → 許容値…）で感度調整。元に戻す / やり直し対応。

パイプライン向け書き出し

  • PNG / JPG / BMP タイルを一括書き出し。名前は自分で制御。
  • 任意のアトラス + JSON（schema atlas_splitter.atlas/v1）：元画像 1 枚 + フレーム表。サンプル矩形と論理キャンバス欄を含み、2D の揃え再生向け。
  • 各フレーム：x,y,w,h = シート上の実サンプル（枠内の不透明外接）；sourceW,sourceH = 論理キャンバス（グリッドセル / フリーのオレンジ枠）；offX,offY = 論理キャンバス左上からのオフセット。全透明セルは恒等（off=0、source=サンプルサイズ）のままになることがあります。
  • グリッド / フリーとも、アトラス書き出し時は論理キャンバス内の不透明領域をサンプルとして記録 — 複数フレームの揃え再生に便利（例：Anim Previewer）。
  • 設定 → 書き出し形式：PNG（透明維持）、JPG / BMP（白背景）、またはソースに合わせる。
  • 設定 → ファイル名テンプレート：デフォルト（名称または tile_###）、{name}、{name}_{index}、tile_{index}。

フリーモードのその他ツール

  • 消しゴム — アルファを消す硬い正方形（1–16 px）。サイズは右クリックまたはダブルクリック。元に戻し可。
  • 不透明範囲に合わせる — 不透明サンプルとオフセットを計算。フリーのオレンジ枠（論理キャンバス）サイズは変えません。
  • ビュー同期 — キャンバス選択とセル一覧を同期（設定 → ビュー同期、デフォルト ON）。
  • パン / ズーム — 移動ツール、ホイール、二本指スクロール、ピンチ。他ツールは Space / 中ボタン。
  • セッション — 未保存の切り分けを次回起動時に復元（ローカルのみ）。

よくある質問

  • 購入後の入手方法は？製品の入手方法へ：Creem 決済 → .dmg ダウンロード → インストール → AS1 キーで有効化。
  • 開き方：ファイル → 開く、ドラッグ＆ドロップ、または Samples。
  • 形式：PNG / JPG / JPEG / BMP。アトラス + JSON も可（offX/offY、sourceW/sourceH — 上記「書き出し」参照）。
  • JSON の off / source は？論理キャンバス上の配置であり、足場 / 中心の pivot ではありません。古いファイルに無い場合は恒等として読みます。
  • 直販版のアクティベートは？購入後、別メールで AS1.… キーが届きます。公証版アプリを開き、AS1. から始まる行をすべて貼り付けて Activate。Mac App Store 版ではこのキーは使いません。
  • Creem 領収書の “license” はキーですか？いいえ。領収書の文字列は Atlas Splitter の有効化キーではありません。有効化メールの AS1.… のみ使ってください。製品の入手方法も参照。
  • 何台の Mac？1 ライセンスで最大 2 台。1 台目はオフライン可。2 台目は短いオンライン席確認が必要。一度有効化した Mac はその後オフラインで使えます。
  • 機種変更は？注文証明を添えてサポートへ旧席の解放を依頼するか、旧 Mac で無効化できる場合はそれを行い、新 Mac で一度オンライン有効化します。
  • 購入後の更新は？領収書 / カスタマーポータルから公証 DMG を再ダウンロードし上書きインストール。同じ AS1 キーを使い続けます。
  • プライバシー：切り出しは Mac 上のみ。詳細はプライバシーポリシー。席確認の通信ではキー id と端末フィンガープリントのハッシュのみ送ります。
