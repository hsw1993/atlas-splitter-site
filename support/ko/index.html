Atlas Splitter

스프라이트 시트와 아틀라스 분할

English · 中文 · 日本語 · 한국어

Atlas Splitter는 인디 게임 개발자와 2D / 픽셀 아티스트를 위한 macOS 아틀라스 분할 도구입니다. 스프라이트 시트, UI 합성, 타일 아틀라스를 끌어다 놓으면 바로 쓸 수 있는 개별 이미지로 나눕니다. 계정 없음, 클라우드 업로드 없음. 에셋은 항상 Mac에 남습니다.

Mac App Store 등록은 심사 중입니다. 출시되면 스토어 링크를 추가합니다. 지금은 공식 사이트에서 일회성 구매할 수 있습니다.

빠른 시작

  1. 아틀라스 열기(드래그 앤 드롭 또는 파일 → 열기).
  2. 그리드 또는 프리 모드 선택.
  3. PNG / JPG / BMP를 일괄 내보낸 뒤 게임 프로젝트에 넣기.

세 가지 명확한 경로

1) 그리드(규칙적 배치)

스프라이트가 정렬되어 있으면 셀 너비/높이, 행/열, 여백, 간격을 설정한 뒤 한 번에 분할합니다.

2) 프리(불규칙 배치)

정렬되지 않았을 때 사용할 수 있는 방법:

  • 마법 봉으로 배경 제거 + 수동 사각형으로 미세 조정
  • 투명 또는 단색 배경을 클릭(자동)해 많은 개별 스프라이트를 박스
  • 셀 목록에서 일괄 이름 변경 및 정리

3) 내보내기 및 가장자리 처리

  • 불투명 영역에 맞춤, 또는 투명 패딩 유지 / 추가
  • 파일 이름 템플릿으로 PNG / JPG / BMP 일괄 내보내기
  • 로컬 처리만 — 업로드 없음, 사용자 데이터 수집 없음

누구를 위한 앱인가

Atlas Splitter는 “SNS용 그리드 자르기”용이 아닙니다. 게임 파이프라인에서 반복되는 분할 작업—큰 시트 안의 수백 개 소품, 캐릭터 프레임, UI 슬라이스—수동 박스는 너무 느리고, 순수 그리드는 자주 맞지 않습니다.

투명하고 형태가 분명한 아틀라스에서는 자동 프레임 + 내보내기가 보통 몇 분 정도입니다. 배경이 복잡하면 프리 + 마법 봉이 안정적인 대안입니다(실행 취소 가능).
