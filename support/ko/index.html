게임 아틀라스를 깔끔한 타일로—빠르게.

English · 中文 · 日本語 · 한국어

최신 도움말 초안(다음 출시용일 수 있음). 출시 스냅샷: App 1.0.0-4. 버전 기록

인디 게임 아트용 Mac 도구입니다. 한 장의 아틀라스에서 자동 프레임, 그리드 또는 프리핸드 박스, 마법 봉 정리 후 로컬로 내보냅니다. 계정 없음, 클라우드 없음. 에셋은 Mac에만 남습니다.

스프라이트가 분명히 떨어져 있을 때 가장 잘 됩니다. 붙거나 배경이 복잡하면 프리핸드 또는 마법 봉을 쓰세요. 공식 사이트에서 일회 구매($7.99). Mac App Store 심사 후 스토어 링크를 추가합니다.

제품 받는 방법

  1. 구매: 홈페이지 또는 Creem 결제 ($7.99 일회성).
  2. 다운로드: Creem에서 공증 .dmg를 다운로드합니다(결제 완료 페이지, 영수증 메일 링크, 또는 고객 포털).
  3. 설치·활성화: Applications에 넣은 뒤 실행하고, 메일의 AS1.… 키를 붙여 넣어 Activate합니다.

전체 안내: atlassplitter.com/get/

빠른 시작

  1. 아틀라스 열기(드래그 앤 드롭 또는 파일 → 열기). 앱에 Samples 포함.
  2. 사이드바에서 그리드 / 프리 전환.
  3. 타일(또는 아틀라스 + JSON)을 선택한 폴더로 내보낸 뒤 게임 프로젝트에 넣기.

기능(공식 사이트 소개과 동일)

자동 프레임

프리 모드에서 배경을 한 번 클릭하면 많은 스프라이트를 한 번에 박스 — 투명 또는 단색 배경의 명확한 시트에 적합. PNG는 투명, JPG/BMP는 단색 키를 클릭. 설정 → 자동 프레임 → 최소 크기…(또는 Auto 도구 더블클릭)로 작은 섬 무시(기본 약 ≤ 8×8).

그리드와 프리핸드

그리드: 규칙적인 타일셋 — 셀 크기, 행/열, 여백, 간격. 셀 크기는 애니메이션 정렬용 논리 캔버스입니다. 가장자리 모드: 자르기(남는 가장자리 픽셀 버림, 완전한 셀만) 또는 패딩(셀 크기 유지, 추가 행/열은 투명). 셀에 마우스를 올리면 미리보기.

프리: 배치가 불규칙하면 사각형을 직접 그림(주황 박스 = 논리 캔버스). 핸들로 크기 조절. 셀 목록에서 정리·이름 변경. 우클릭으로 불투명 영역에 맞춤 / 목록에 추가 / 이미지 복사 / 삭제. 겹침: 우클릭 → 선택 → #id.

마법 봉

자동 프레임 후 배경이 지저분하면 선택해 투명으로 지웁니다. 불투명 픽셀 클릭, Shift+클릭으로 추가. 우클릭: 1px 확장 / 1px 축소 / 투명으로 / 반전 / 선택 해제. 봉 더블클릭(또는 설정 → 마법 봉 → 허용치…)으로 감도 조절. 실행 취소 / 다시 실행 지원.

파이프라인용 내보내기

  • PNG / JPG / BMP 타일을 일괄 내보내기. 이름은 직접 제어.
  • 선택적 아틀라스 + JSON(schema atlas_splitter.atlas/v1): 원본 시트 + 프레임 표. 샘플 사각형과 논리 캔버스 필드를 포함하며 2D 정렬 재생용.
  • 프레임마다: x,y,w,h = 시트상 실제 샘플(박스 안 불투명 외접); sourceW,sourceH = 논리 캔버스(그리드 셀 / 프리 주황 박스); offX,offY = 논리 캔버스 좌상단 기준 오프셋. 완전 투명 셀은 항등(off=0, source=샘플 크기)일 수 있음.
  • 그리드·프리 모두 아틀라스 내보내기 시 논리 캔버스 안 불투명 영역을 샘플로 기록 — 다중 프레임 정렬 재생에 유리(예: Anim Previewer).
  • 설정 → 내보내기 형식: PNG(투명 유지), JPG / BMP(흰 배경), 또는 원본 따름.
  • 설정 → 파일명 템플릿: 기본(이름 또는 tile_###), {name}, {name}_{index}, tile_{index}.

프리 모드의 도구

  • 지우개 — 알파를 지우는 하드 사각(1–16 px). 우클릭 또는 더블클릭으로 크기. 실행 취소 가능.
  • 불투명 영역에 맞춤 — 불투명 샘플과 오프셋을 계산. 프리 주황 박스(논리 캔버스) 크기는 유지.
  • 차트 연동 — 캔버스 선택과 셀 목록 동기화(설정 → 차트 연동, 기본 켜짐).
  • 이동 / 확대 — Move 도구, 휠, 두 손가락 스크롤, 핀치. 다른 도구는 Space / 가운데 버튼.
  • 세션 — 저장되지 않은 작업을 다음 실행 시 복원(로컬만).

자주 묻는 질문

  • 구매 후 제품은 어떻게 받나요? 제품 받는 방법: Creem 결제 → .dmg 다운로드 → 설치 → AS1 키로 활성화.
  • 여는 방법: 파일 → 열기, 드래그 앤 드롭, 또는 Samples.
  • 형식: PNG / JPG / JPEG / BMP. 아틀라스 + JSON도 가능(offX/offY, sourceW/sourceH — 위 「내보내기」 참고).
  • JSON의 off / source는? 논리 캔버스 배치이며 발/중심 pivot이 아닙니다. 없는 구버전 파일은 가져올 때 항등으로 처리합니다.
  • 직판판 활성화는? 구매 후 별도 활성화 메일로 AS1.… 키를 받습니다. 공증된 앱을 열고 AS1.로 시작하는 줄 전체를 붙여 넣은 뒤 활성화하세요. Mac App Store 빌드는 이 키를 쓰지 않습니다.
  • Creem 영수증의 “license”가 키인가요? 아닙니다. 영수증 코드는 Atlas Splitter 활성화 키가 아닙니다. 활성화 메일의 AS1.…만 사용하세요. 제품 받는 방법도 참고하세요.
  • Mac 몇 대? 라이선스당 최대 2대. 첫 Mac은 오프라인 활성화 가능하고, 두 번째 Mac은 짧은 온라인 좌석 확인이 필요합니다. 이미 활성화된 Mac은 계속 오프라인으로 쓸 수 있습니다.
  • 기기를 바꾸려면? 주문 증빙과 함께 지원에 문의해 이전 좌석을 비우거나, 가능하면 이전 Mac에서 비활성화한 뒤 새 Mac에서 한 번 온라인 활성화하세요.
  • 구매 후 업데이트는? 영수증 / 고객 포털에서 공증 DMG를 다시 받아 덮어 설치하고, 같은 AS1 키를 계속 사용하세요.
  • 개인정보: 자르기는 Mac에서만 처리합니다. 자세한 내용은 개인정보 처리방침. 온라인 좌석 확인 시 키 id와 기기 지문 해시만 전송합니다.
