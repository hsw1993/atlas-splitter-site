Quick facts / 要点

  • No key: Open the app from Launchpad / Applications and use it. Do not paste Creem or AS1.… codes.
  • 无密钥：从启动台或「应用程序」打开即可用。不要粘贴 Creem / AS1.… 密钥。
  • Updates: Mac App Store → Updates.
  • 更新：Mac App Store → 更新。
  • Refunds: Request through Apple (Report a Problem / purchase history) — not Creem.
  • 退款：通过 Apple（问题报告 / 购买记录），不是 Creem。

Sandbox tips / 沙盒提示

  • Prefer File → Open (and Choose Output Folder) so macOS grants access. Drag-and-drop may be limited under App Sandbox.
  • 商店版在沙盒下：请用文件 → 打开与选择导出目录；拖放可能受限。
  • Sample atlases ship inside the app (Help path / Samples) for App Review and first try.
