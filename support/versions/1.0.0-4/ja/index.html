履歴スナップショット：App 1.0.0-4（Creem DMG AtlasSplitter-1.0.0-4.dmg）。すべてのバージョン · 最新ヘルプ

インディーゲーム向け Mac 切り分けツール。1 枚のアトラスから自動フレーム、グリッド / フリー描画、魔法の杖での清掃、そしてローカル書き出し。アカウント不要・クラウドなし。素材は Mac に残ります。

スプライトがはっきり分かれているときに最も効果的。粘着や複雑な背景はフリーまたは杖で補ってください。公式サイトで買い切り（$7.99）。Mac App Store 審査後にストアリンクを追加します。

クイックスタート

  1. アトラスを開く（ドラッグ＆ドロップ、または ファイル → 開く）。アプリ内に Samples あり。
  2. サイドバーでグリッド / フリーを切替。
  3. タイル（またはアトラス + JSON）を選んだフォルダへ書き出し、ゲームプロジェクトへ投入。

できること（公式サイトの紹介と一致）

自動フレーム

フリーモードで背景を 1 回クリックすると、多数のスプライトを一括枠取り — 透明または単色塗りで分かれているシート向け。PNG は透明、JPG/BMP は単色キーをクリック。設定 → 自動フレーム → 最小サイズ…（または自動ツールをダブルクリック）で小さい島を無視（デフォルト約 ≤ 8×8）。

グリッドとフリーハンド

グリッド：規則的なタイルセット — セルサイズ、行/列、マージン、間隔。端の処理：切り抜き（端の余りを破棄、完全なセルのみ）またはパディング（セルサイズ維持、余分な行列は透明）。セルにホバーでプレビュー。

フリー：不規則な配置は矩形を手描き。ハンドルでリサイズ。セル一覧で整理・リネーム。右クリックで不透明範囲に合わせる / リストに追加 / 画像をコピー / 削除。重なり：右クリック → 選択 → #id。

魔法の杖

自動フレームのあとが汚れているときに、背景を選んで透明化。不透明をクリック、Shift+クリックで追加。右クリック：1px 拡張 / 1px 縮小 / 透明化 / 反転 / 選択解除。杖をダブルクリック（または 設定 → 魔法の杖 → 許容値…）で感度調整。元に戻す / やり直し対応。

パイプライン向け書き出し

  • PNG / JPG / BMP タイルを一括書き出し。名前は自分で制御。
  • 任意のアトラス + JSON（1 枚のシート + フレーム表）。
  • 設定 → 書き出し形式：PNG（透明維持）、JPG / BMP（白背景）、またはソースに合わせる。
  • 設定 → ファイル名テンプレート：デフォルト（名称または tile_###）、{name}、{name}_{index}、tile_{index}。

フリーモードのその他ツール

  • 消しゴム — アルファを消す硬い正方形（1–16 px）。サイズは右クリックまたはダブルクリック。元に戻し可。
  • 不透明範囲に合わせる — フリー / 選択セルを非透明ピクセルに合わせて縮小。
  • ビュー同期 — キャンバス選択とセル一覧を同期（設定 → ビュー同期、デフォルト ON）。
  • パン / ズーム — 移動ツール、ホイール、二本指スクロール、ピンチ。他ツールは Space / 中ボタン。
  • セッション — 未保存の切り分けを次回起動時に復元（ローカルのみ）。
