Atlas Splitter is a macOS atlas slicing tool for indie game developers and 2D / pixel artists. Drag in a sprite sheet, UI composite, or tile atlas and split it into ready-to-use individual images — no account, no cloud upload. Your assets always stay on your Mac.

Quick start

  1. Open an atlas (drag & drop or File → Open).
  2. Choose Grid or Free mode.
  3. Batch export PNG / JPG / BMP — then drop the tiles into your game project.

Three clear paths

1) Grid (regular layouts)

When sprites are aligned, set cell width/height, rows/columns, margins, and spacing — then split the whole sheet in one go.

2) Free (irregular layouts)

When sprites are not aligned, you can:

  • Use Magic Wand background removal + manual rectangles for fine tuning
  • Click transparent or solid-color background (Auto) to frame many individual sprites
  • Batch rename and organize items in the Cells list

3) Export & edge handling

  • Trim to content, or keep / add transparent padding
  • Batch export PNG / JPG / BMP with filename templates
  • Local processing only — no uploads, no user data collection

Who it’s for

Atlas Splitter isn’t for “social-media grids”. It’s for the repetitive slicing work in game pipelines: hundreds of props, character frames, and UI slices inside one large sheet — manual boxing is too slow, and pure grids often don’t line up.

On transparent atlases with clear connected shapes, Auto Frame + export is typically around a couple of minutes. When backgrounds are complex, Free mode + Magic Wand is a reliable fallback — with undo and iterative edits.
