Quick start

  1. Open an atlas (drag & drop or File → Open). Sample atlases are in the app bundle.
  2. Use the sidebar to switch Grid or Free (freehand) mode.
  3. Export tiles (or atlas + JSON) to a folder you choose — then drop them into your game project.

Capabilities (as on the product site)

Auto Frame

In Free mode, click the background once to box many sprites at once — ideal for clear sheets on transparent or solid fills. PNG: click transparent; JPG/BMP: click the solid key color. Settings → Auto Frame → Min Size… (or double-click the Auto tool) skips tiny islands (default about ≤ 8×8).

Grid & Freehand

Grid: regular tilesets — set cell size, rows/columns, margins, and spacing. Cell size is the logical canvas used for animation alignment. Edge modes: Crop (discard leftover edge pixels; full cells only) or Pad (keep cell size; extra rows/cols filled with transparency). Hover a cell to preview the tile.

Free (Freehand): draw rectangles when the layout is irregular (orange box = logical canvas); resize with handles; organize and rename in the Cells list. Right-click a box for Trim to content, Add to list, Copy Image, or Delete. Overlapping boxes: right-click → Select → #id.

Magic Wand

Select and clear backgrounds to transparency when Auto Frame needs a cleaner pass. Click opaque pixels; Shift+click to add. Right-click: Expand 1px / Contract 1px / Make transparent / Invert / Deselect. Double-click the Wand tool (or Settings → Wand → Tolerance…) to adjust sensitivity. Undo / Redo supported.

Export for your pipeline

  • Batch-export individual PNG / JPG / BMP tiles with names you control.
  • Optional Atlas + JSON (schema atlas_splitter.atlas/v1): full sheet + frame table, with sample rect plus logical-canvas fields for aligned 2D playback.
  • Per frame: x,y,w,h = sample rect on the sheet (opaque bounds inside the box); sourceW,sourceH = logical canvas (grid cell / Free orange box); offX,offY = sample offset from the canvas top-left. Fully transparent cells may stay identity (off=0 and source equals sample size).
  • Grid and Free atlas export both write the opaque sample inside each logical canvas — helpful for aligned playback (e.g. companion Anim Previewer).
  • Settings → Export Format: PNG (keeps transparency), JPG / BMP (white background), or match source.
  • Settings → Filename Template: Default (Name or tile_###), {name}, {name}_{index}, tile_{index}.

More tools in Free mode

  • Eraser — hard square brush clears alpha (1–16 px); right-click or double-click the tool for size; undo available.
  • Trim to content — compute the opaque sample and offset; the Free orange box (logical canvas) size stays the same.
  • View Sync — keep canvas selection synced with the Cells list (Settings → View Sync; on by default).
  • Pan / zoom — Move tool, mouse wheel, two-finger scroll, pinch; Space / middle-mouse pan on other tools.
  • Session — unsaved slicing can be restored on next launch (local only).

Common questions

  • How do I get the product after buying? See How to get the product: Creem checkout → download .dmg from Creem → install → activate with AS1 key.
  • How do I open an image? File → Open, drag & drop, or use Samples in the app bundle.
  • Which formats? Open and export PNG / JPG / JPEG / BMP. Export can also write Atlas + JSON (with offX/offY, sourceW/sourceH — see Export above).
  • What are off / source in the JSON? Logical canvas placement (sample offset inside the box), not a foot/center pivot. Older files missing these fields are treated as identity on import.
  • How do I activate a direct-sale license? After purchase you receive an AS1.… key by email. Open the notarized app, paste the full key when prompted, then Activate. Mac App Store builds do not use this key.
  • How many Macs? One license covers 2 Macs. The first Mac can activate offline; activating on a second Mac needs a short online seat check. Already-activated Macs keep working offline.
  • How do I move to a new Mac? Email support with your order proof to free an old seat, or deactivate on the old Mac when available — then activate on the new Mac (online once).
  • How do I update after buying? Re-download the notarized .dmg from Creem (receipt email link or customer portal), install over the previous copy, and keep using the same AS1 key.
  • Privacy? Processing is local on your Mac — see the Privacy Policy. Seat checks (when online) only send a key id and a machine fingerprint hash.
