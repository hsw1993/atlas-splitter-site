Quick start

  1. Open an atlas (drag & drop or File → Open). Sample atlases are in the app bundle.
  2. Use the sidebar to switch Grid or Free (freehand) mode.
  3. Export tiles (or atlas + JSON) to a folder you choose — then drop them into your game project.

Capabilities (as on the product site)

Creem package 1.0.0-7: Grid, Free (Auto Frame, Rect, Select, Wand), and export are included. Eraser and Trim to content are not. Atlas JSON still writes offX/offY/sourceW/sourceH, but as identity (aligned to each sample) for schema compatibility.

Auto Frame

In Free mode, click the background once to box many sprites at once — ideal for clear sheets on transparent or solid fills. PNG: click transparent; JPG/BMP: click the solid key color. Settings → Auto Frame → Min Size… (or double-click the Auto tool) skips tiny islands (default about ≤ 8×8).

Grid & Freehand

Grid: regular tilesets — set cell size, rows/columns, margins, and spacing. Cell size is the logical canvas used for animation alignment. Edge modes: Crop (discard leftover edge pixels; full cells only) or Pad (keep cell size; extra rows/cols filled with transparency). Hover a cell to preview the tile.

Free (Freehand): draw rectangles when the layout is irregular; resize with handles; organize and rename in the Cells list. Right-click a box for Add to list, Copy Image, or Delete. Overlapping boxes: right-click → Select → #id.

Magic Wand

Select and clear backgrounds to transparency when Auto Frame needs a cleaner pass. Click opaque pixels; Shift+click to add. Right-click: Expand 1px / Contract 1px / Make transparent / Invert / Deselect. Double-click the Wand tool (or Settings → Wand → Tolerance…) to adjust sensitivity. Undo / Redo supported.

Export for your pipeline

  • Batch-export individual PNG / JPG / BMP tiles with names you control.
  • Optional Atlas + JSON (schema atlas_splitter.atlas/v1): full sheet + frame table with x,y,w,h and schema fields offX/offY/sourceW/sourceH.
  • On Creem 1.0.0-7, those off/source fields are written as identity (off=0, source size equals sample size). Non-identity logical-canvas editing is not in this package.
  • Settings → Export Format: PNG (keeps transparency), JPG / BMP (white background), or match source.
  • Settings → Filename Template: Default (Name or tile_###), {name}, {name}_{index}, tile_{index}.

More tools in Free mode

  • Eraser — not in Creem 1.0.0-7; may appear in MAS / fuller builds (hard square brush clears alpha).
  • Trim to content — not in Creem 1.0.0-7; may appear in MAS / fuller builds.
  • View Sync — keep canvas selection synced with the Cells list (Settings → View Sync; on by default).
  • Pan / zoom — Move tool, mouse wheel, two-finger scroll, pinch; Space / middle-mouse pan on other tools.
  • Session — unsaved slicing can be restored on next launch (local only).

Who it’s for

Written for indie game developers and artists. The author is an indie developer too: open texture communities are full of atlases, but pulling sprites out quickly is awkward, and full image editors are often too heavy when you only need to cut tiles. Atlas Splitter keeps that job light — open a sheet, frame, export on your Mac. If you like, you can also use Grid for social-media layouts, Wand to cut out backgrounds, and Copy Image to the clipboard so you can paste into other graphics apps. On clear transparent atlases, Auto Frame + export is often about a couple of minutes. Complex backgrounds: Freehand + Wand, iteratively, with undo.

Common questions

  • How do I get the product after buying? See How to get the product: Creem checkout → download .dmg from Creem → install → activate with AS1 key.
  • How do I open an image? File → Open, drag & drop, or use Samples in the app bundle.
  • Which formats? Open and export PNG / JPG / JPEG / BMP. Export can also write Atlas + JSON (schema fields include offX/offY, sourceW/sourceH — identity on Creem 1.0.0-7; see Export above).
  • What are off / source in the JSON? Schema fields for sample placement inside a logical canvas. On Creem 1.0.0-7 they are identity. Older files missing these fields are treated as identity on import.
  • How do I activate a direct-sale license? After purchase you receive a separate activation email with an AS1.… key. Open the notarized app, paste the entire key (line starting with AS1.) — use Paste from Clipboard if ⌘V is awkward — then Activate. Mac App Store builds do not use this key.
  • How long until the activation key email arrives? Usually within 12–24 hours after a successful order (often sooner). Check spam if nothing arrives; after 24 hours email 917097871@qq.com with your order ID.
  • Creem’s receipt shows a “license” string — is that my key? No. Creem receipt codes are not Atlas Splitter activation keys. Use only the AS1.… key from the activation email. See How to get the product.
  • How many Macs? One license covers 2 Macs. The first Mac can activate offline; activating on a second Mac needs a short online seat check. Already-activated Macs keep working offline.
  • How do I move to a new Mac? On the old Mac: Help → Deactivate This Mac… (releases the seat and quits). Then activate on the new Mac once online. Or email support with order proof to free a seat.
  • How do I update after buying? Re-download the notarized .dmg from Creem (receipt email link or customer portal), install over the previous copy, and keep using the same AS1 key.
  • Does every build include Eraser / Trim? Mac App Store and full builds may. The reduced Creem direct-sale package can omit Eraser and Trim to content; activation and the rest of Grid / Free / Wand / export still apply.
  • Privacy? Processing is local on your Mac — see the Privacy Policy. Seat checks (when online) only send a key id and a machine fingerprint hash.
