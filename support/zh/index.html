面向独立游戏美术的 Mac 切图工具：一张图集自动框选、网格或手绘框、魔棒清理，再本机导出。无账号、不上传，素材只留在你的 Mac。

图元分离清晰时效果最好；粘连或背景复杂时，用手绘或魔棒补。官网首页可一次性购买（$7.99）。Mac App Store 过审后会在此补充商店链接。

快速开始

  1. 打开图集（拖放或「文件 → 打开」）。应用内附带 Samples 样例。
  2. 侧栏切换网格或手绘模式。
  3. 导出小图（或图集 + JSON）到你选择的文件夹，再放进游戏工程。

能力（与官网介绍一致）

Creem 包 1.0.0-7：含网格、手绘（自动框选 / 矩形 / 选择 / 魔棒）与导出。不含橡皮与「收紧到内容」。图集 JSON 仍会写入 offX/offY/sourceW/sourceH，但为恒等（与采样对齐），仅保证 schema 兼容。

自动框选

在手绘模式中点一下背景，即可批量框出图元——透明底或纯色底效果最好。PNG 点透明；JPG/BMP 点实色底。设置 → 自动框选 → 最小尺寸…（或双击「框选」工具）可忽略过小岛（默认约 ≤ 8×8）。

网格与手绘

网格：规整 tileset — 设置格子大小、行列、外边距与间距。格子尺寸即逻辑画布（动画对齐用）。边缘模式：裁掉余量（丢弃凑不满一格的边缘像素）或透明补边（格子大小不变，多出的行列用透明填充）。悬停格子可预览图元。

手绘：布局不规则时自由画框；拖手柄改大小；在单元列表中整理与重命名。右键可「加入列表」「复制图像」「删除」。重叠时：右键 → 选中 → #id。

魔棒

自动框选不够干净时，用魔棒选区并清成透明。点击不透明像素；Shift+点击加选。右键：扩张 1px / 收缩 1px / 设为透明 / 反选 / 取消选择。双击魔棒（或 设置 → 魔棒 → 容差…）调节灵敏度。支持撤销 / 重做。

导出到你的管线

  • 批量导出 PNG / JPG / BMP 小图，文件名可按习惯控制。
  • 可选图集 + JSON（schema atlas_splitter.atlas/v1）：原图整图 + 帧表，含 x,y,w,h 与 schema 字段 offX/offY/sourceW/sourceH。
  • Creem 1.0.0-7 中，上述 off/source 字段按恒等写入（off=0，source 尺寸等于采样）。本包不含非恒等逻辑画布编辑。
  • 设置 → 导出格式：PNG（保留透明）、JPG / BMP（白底），或跟随源图。
  • 设置 → 文件名模板：默认（名称或 tile_###）、{name}、{name}_{index}、tile_{index}。

手绘模式更多工具

  • 橡皮 — Creem 1.0.0-7 不含；可能出现在 MAS / 完整版。
  • 收紧到内容 — Creem 1.0.0-7 不含；可能出现在 MAS / 完整版。
  • 图表联动 — 画布选区与单元列表同步（设置 → 图表联动；默认开启）。
  • 平移 / 缩放 — 移动工具、滚轮、双指滑动、捏合；其它工具可用 Space / 中键平移。
  • 会话 — 未保存的切图可在下次启动时恢复（仅本机）。
