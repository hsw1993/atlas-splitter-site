Atlas Splitter

分割精灵表与图集

English · 中文 · 日本語 · 한국어

Atlas Splitter 是面向独立游戏开发者与 2D / 像素美术的 macOS 图集切分工具。拖入精灵表、UI 拼图或瓦片图集，即可切成可直接使用的单张图片——无需账号、不上传云端，素材始终留在你的 Mac 上。

Mac App Store 上架审核中，通过后会在此补充商店链接。当前也可在官网首页一次性购买。

快速开始

  1. 打开图集（拖放，或「文件 → 打开」）。
  2. 选择网格或手绘模式。
  3. 批量导出 PNG / JPG / BMP，再放进你的游戏工程。

三条清晰路径

1）网格（规则布局）

精灵排列整齐时，设置格子宽高、行列、外边距与间距，一次切完整张图。

2）手绘（不规则布局）

排列不规整时，你可以：

  • 用魔棒去背景 + 手动画框微调
  • 点击透明或纯色背景（框选）自动框出大量单体
  • 在单元列表中批量重命名与整理

3）导出与边缘处理

  • 收紧到内容，或保留 / 增加透明边距
  • 按文件名模板批量导出 PNG / JPG / BMP
  • 仅本机处理——不上传、不收集用户数据

适合谁

Atlas Splitter 不是做「社交媒体九宫格」的。它面向游戏管线里反复出现的切图：一张大图里成百上千道具、角色帧与 UI 切片——手动画框太慢，纯网格又经常对不齐。

透明底、形状清晰的图集，自动框选 + 导出通常大约两分钟。背景复杂时，用手绘 + 魔棒迭代修改（可撤销）更稳妥。
